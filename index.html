Bitcoin Cash governance

How network consensus works

Protocol changes emerge through public discussion, implementation, and voluntary adoption by the people and organizations running the network.

  1. Discuss the proposalCommunity members and developers debate ideas in public forums such as BitcoinCashResearch.org.
  2. Document and reviewProposals are specified and reviewed through the Cash Improvement Proposals process.
  3. Build and test implementationsNode software teams can implement the proposal, invite review, and test changes before activation.
  4. Participants choose what to runMiners, businesses, exchanges, and users independently decide which software and compatible network rules they support.
  5. Nodes validate by their rulesEach node independently checks blocks and transactions against the consensus rules in its software.

A discussion or proposal does not automatically change the protocol. Changes depend on implementation and adoption by network participants.
